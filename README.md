# FuckIP 独角鲸 显示增强脚本

这是一个针对 **fuckip.me 独角鲸** 的油猴增强脚本，用于自动计算并展示每种服务器类型的「最低配置价格」，并对价格进行颜色分级和自动排序，帮助快速选择性价比最高的方案。

---

## ✨ 功能特性

### 1️⃣ 自动计算最低配置价格  
- 读取 `/api/server-configs` 接口数据  
- 按每个配置项的最小值（min/default）计算总价  
- 实时展示在服务器类型标签旁  

---

### 2️⃣ 价格颜色分级  

根据最低价自动上色：

- 🟢 ≤ 0.1 —— 绿色（超低价）
- 🟠 0.1 ~ 0.3 —— 橙色（正常）
- 🟡 > 0.3 —— 黄色（偏高）

让便宜机器一眼可见。

---

### 3️⃣ 自动按价格升序排序  

- ✅ 未售罄服务器：按最低价从低到高排列  
- 🚫 已售罄服务器：自动排到最后  

避免被高价或缺货机器干扰选择。

---

### 4️⃣ 完全兼容 SPA 页面  

- 自动监听路由变化  
- 切换地区自动刷新  
- 不重复插入价格  
- 不破坏原页面 DOM 结构  

---

## 🎯 使用场景

- 快速找最低价机器  
- 批量对比不同地区价格  
- 挖掘隐藏低价配置  
- 避免误选高价机型
